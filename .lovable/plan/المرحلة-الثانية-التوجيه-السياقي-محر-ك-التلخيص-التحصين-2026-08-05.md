# المرحلة الثانية: التوجيه السياقي + محرّك التلخيص + التحصين

## 1. التوجيه الموجَّه بالحالة (State-Driven Routing)

سجل موحّد للميزات (`src/lib/features.ts`) يحدد لكل ميزة: المعرّف، الاسم العربي، الأيقونة، الوصف، نص الشريط الإرشادي، ونوع نافذة الإعدادات. الشاشة الرئيسية تُبنى من هذا السجل (مبدأ DRY) بدل تكرار البطاقات.

التنقل يمرّر الميزة كـ search param مُتحقَّق منه:
`/library?feature=summarize` — عبر `validateSearch` في مسار المكتبة، لذا الحالة محفوظة عند التحديث أو مشاركة الرابط (لا تُفقد كما يحدث مع state داخلي).

رحلة المستخدم:
1. ضغط بطاقة ميزة → المكتبة مع `feature=...`
2. المكتبة تُظهر شريطاً سياقياً بارزاً: "اختر ملف PDF لاستخدامه مع [الميزة]" + زر إلغاء الوضع.
3. في هذا الوضع النقر على ملف لا يفتحه للقراءة بل يفتح نافذة الإعدادات.
4. نافذة سفلية (Bottom Sheet) ديناميكية قابلة لإعادة الاستخدام: للتلخيص حقلا "من صفحة / إلى صفحة" + خيار "المادة كاملة" + زر "ابدأ التلخيص". لبقية الميزات نموذج إعدادات مناسب (عدد البطاقات، الصوت… إلخ).
5. التنفيذ: إغلاق النافذة، حالة تحميل انسيابية (Shimmer)، إرسال المستند + الإعدادات إلى الذكاء الاصطناعي في الخلفية، ثم الانتقال لصفحة نتيجة الملخص.

## 2. محرّك الذكاء الاصطناعي (يعمل فعلياً)

- استخراج نص PDF داخل المتصفح (pdfjs) مع احترام نطاق الصفحات، وتقطيع ذكي (Chunking) مع الحفاظ على رقم الصفحة لكل مقطع.
- التلخيص عبر دوال خادم (`createServerFn`) تستدعي بوابة Lovable AI بنموذج قوي جداً (Gemini 3.6 Flash افتراضياً وGPT‑5.5 للمهام الثقيلة) — المفتاح يبقى في الخادم ولا يُعرَض للعميل إطلاقاً.
- المخرجات منظمة (JSON Schema): تعريفات ومصطلحات، قوانين ومعادلات، تواريخ، جداول مقارنة، وأهم النقاط — مع **رقم الصفحة** لكل بند (ميزة التوثيق والمصدر).
- بثّ مباشر للنتيجة (streaming) لتفادي أي انتظار صامت أو مهلة.
- معالجة صريحة لأخطاء 429 (تجاوز الحد) و402 (نفاد الرصيد) برسائل عربية واضحة.

## 3. قاعدة البيانات (Migration)

- جدول `summaries`: المستند، نطاق الصفحات، المحتوى المنظم، الحالة، الميزة المستخدمة.
- جدول `document_chunks` مع `pgvector` لتخزين نصوص الكتاب ومتجهاتها (أساس RAG للأستاذ الرقمي لاحقاً) + فهرس تشابه.
- فهارس على `documents(user_id, created_at)`, `summaries(user_id, document_id)`, `document_chunks(document_id)`.
- RLS صارمة على الجديد: كل مستخدم يرى ويكتب صفوفه فقط، مع GRANT للأدوار المصرح لها فقط.

## 4. الأمان والتحقق

- تحقق Zod على كل مدخلات الدوال الخادمية والنماذج (نطاق صفحات منطقي، أطوال نصوص، تعقيم).
- تحقق من الملفات المرفوعة: نوع MIME + توقيع PDF (%PDF) + الحجم، ومسار تخزين مربوط بمعرّف المستخدم.
- لا عرض HTML خام من مخرجات الذكاء الاصطناعي (لا `dangerouslySetInnerHTML`).
- الجلسات عبر JWT الحالي، والنقل عبر HTTPS، وسياسات التخزين مفعّلة أصلاً.

## 5. الأداء والسلاسة

- React Query كطبقة تخزين مؤقت: `staleTime` معقول، بيانات محفوظة عبر التنقل، وتحديث تفاؤلي للحذف/الرفع.
- Skeleton/Shimmer لقوائم المكتبة والملخصات بدل نص "جارٍ التحميل".
- تحميل pdfjs ومكوّنات النتيجة بشكل مُتأخر (lazy) حتى لا تثقل الإقلاع.
- استخراج النص وتقطيعه بعمليات غير متزامنة على دفعات لمنع تجميد الواجهة.

## ملاحظات تقنية
مسار جديد `/_authenticated/summary/$id` لعرض الملخص، ومكوّن `FeatureSheet` عام يبني حقوله من سجل الميزات. الميزات غير المنجَزة بعد (الصوت، OCR، الخرائط) تعرض نافذتها مع رسالة "قريباً" بدل تنقّل مضلل.

## نطاق هذه الجولة
التوجيه السياقي + نافذة الإعدادات + التلخيص العامل بالكامل + الملخصات المحفوظة + الأمان والفهارس وpgvector + تحسينات الأداء. باقي الميزات (الاختبارات، البطاقات، الصوت، المجتمع) في جولات لاحقة على نفس الأساس.
