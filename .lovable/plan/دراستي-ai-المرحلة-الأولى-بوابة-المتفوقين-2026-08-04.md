# دراستي AI — المرحلة الأولى: بوابة المتفوقين

## ملاحظة عن شكل التطبيق

هذه المنصة تبني تطبيقات ويب. الحل العملي: نبنيه كتطبيق ويب بمظهر موبايل أصلي (PWA) — واجهة عربية RTL كاملة، شريط تنقّل سفلي، حركات وانتقالات، ويمكن للطالب "إضافته إلى الشاشة الرئيسية" ليعمل بملء الشاشة بدون شريط المتصفح. لاحقاً يمكن تغليفه بـ Capacitor لمتاجر أندرويد/iOS بنفس الكود.

## الهوية البصرية

اللون الأساسي: أزرق ملكي دافئ (#2563EB) + لمسة كهرمانية (#F59E0B) للإنجازات — مريح للقراءة الطويلة ومألوف للطلاب. خط عربي: Cairo للعناوين + IBM Plex Sans Arabic للنصوص. وضع فاتح وداكن من البداية.

## نطاق هذه المرحلة

بناء أساس التطبيق + قسم "بوابة المتفوقين" كاملاً وجاهزاً للتوسّع.

### 1. الأساس (Foundation)

- تفعيل Lovable Cloud (قاعدة بيانات + مصادقة + تخزين ملفات).
- ضبط RTL كاملاً على مستوى التطبيق، نظام تصميم بألوان دلالية، وضع داكن/فاتح.
- هيكل موبايل: شاشة بمقاس هاتف، شريط تنقّل سفلي بأربعة أقسام (الرئيسية، مكتبتي، الأستاذ الرقمي، حسابي) — الأقسام غير المنفذة تظهر كبطاقات "قريباً" واضحة، لا صفحات مكسورة.

### 2. الهوية الرقمية (Smart Auth)

- شاشة ترحيب (Onboarding) بثلاث لوحات تشرح التطبيق.
- صفحة مصادقة واحدة: تسجيل دخول / إنشاء حساب بالبريد وكلمة المرور + زر "الدخول بحساب Google".
- استعادة كلمة المرور: إرسال رابط + صفحة تعيين كلمة مرور جديدة.
- تحقق من المدخلات مع رسائل خطأ عربية واضحة.
- حماية الصفحات: أي صفحة داخلية تُوجّه غير المسجّل إلى صفحة المصادقة، والزر في الأعلى يتغيّر حسب حالة الجلسة، مع تسجيل خروج نظيف.

### 3. المستودع السحابي (Cloud Vault)

- ملف شخصي للطالب: الاسم، المرحلة الدراسية، ، الصورة الرمزية — يُنشأ تلقائياً عند التسجيل.
- تخزين سحابي آمن لملفات الطالب (PDF) مع صلاحيات خاصة لكل مستخدم.
- جداول جاهزة للأقسام القادمة: المواد/الملازم، الملخصات، البطاقات، الاختبارات، سجلات المحادثة — كلها مربوطة بالطالب ومحمية.
- شاشة "مكتبتي": عرض ملفات الطالب مع رفع ملف PDF وحذفه (بدون تلخيص بعد — التلخيص في المرحلة الثانية).

### 4. مركز القيادة (نسخة أولى)

- تعديل الملف الشخصي والصورة.
- تبديل الوضع الداكن/الفاتح.
- الدعم والمساعدة + تسجيل الخروج.

## التفاصيل التقنية

- الواجهة: React 19 + TanStack Start، Tailwind v4، shadcn/ui، رموز تصميم دلالية في `src/styles.css`.
- الخلفية: Lovable Cloud (Postgres + Auth + Storage) مع RLS صارم على كل جدول (`auth.uid()`)، وGRANT صريحة.
- Google OAuth عبر وسيط Lovable + تفعيل مزوّد Google في إعدادات المصادقة.
- الجداول: `profiles`, `documents`, `subjects` (+ حقول جاهزة للتوسّع)؛ bucket خاص `study-files`.
- الأدوار في جدول `user_roles` منفصل (استعداداً لساحة التحدي والمجتمع لاحقاً) — لا تُخزّن في `profiles`.
- بنية نظيفة: `src/routes` للصفحات، `src/features/<feature>` للمنطق، `src/components/ui` للعناصر، `src/lib/*.functions.ts` لدوال السيرفر.
- SEO: عنوان ووصف عربي مخصص لكل صفحة.
